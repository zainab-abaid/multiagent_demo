# Repository Setup Guide

This guide shows you how to set up a minimal repository with only the essential files for the agent and evaluation system.

## Essential Files to Include

### Core Agent Code
- `agent/` - Complete agent directory with all node implementations and tools
- `debug_agent.py` - Interactive debugging tool
- `evaluate_agent.py` - Evaluation framework

### Ground Truth Data
- `composite_queries.jsonl` - Evaluation queries with expected answers and tool calls

### Supporting Files
- `init_rag_store.py` - Script to initialize RAG vector store
- `documents/` - Text documents for RAG (company info, pricing policy, etc.)
- `requirements.txt` - Python dependencies

### Optional (Auto-generated or Auto-downloaded)
- `Chinook.db` - SQLite database (will be auto-downloaded if missing)
- `chroma_db/` - RAG vector store (will be generated by init_rag_store.py)
- `.env` - Environment variables (create from template)

## Files to Exclude

All of these should be in `.gitignore`:
- `logs/` - Evaluation logs (generated)
- `__pycache__/` - Python cache files
- `.env` - API keys (security)
- Documentation files not needed for running (e.g., `*.md` except README)

## Quick Setup

1. **Create `.env` file:**
   ```
   OPENAI_API_KEY=your_key_here
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize RAG store:**
   ```bash
   python init_rag_store.py
   ```

4. **Test the agent:**
   ```bash
   python debug_agent.py "What is the total revenue for 2011?"
   ```

5. **Run evaluation:**
   ```bash
   python evaluate_agent.py composite_queries.jsonl comp_9
   ```
